# 🎯 Number Guessing Game

A simple **C program** where the computer generates a random number and the player tries to guess it.

## 🛠️ Built With

- C
- `if-else`
- `while` loop
- Random numbers
- User input

## 🎮 How It Works

1. Computer generates a random number between **1 and 100**.
2. Player enters a guess.
3. The program tells whether the guess is **too high** or **too low**.
4. The game continues until the correct number is guessed.
5. The number of attempts is displayed.

## ▶️ Run

```bash
gcc guess_the_number.c -o guess_the_number
./guess_the_number
```

## 📌 Example

```text
Guess the number between 1 and 100: 40
Too low!

Guess the number between 1 and 100: 75
Too high!

Guess the number between 1 and 100: 63
Correct!
```
